# Spec Delta

## Purpose

Выбор первичной единицы отображения расходов — кредиты z.ai или доллары — настройкой
`claudeStatus.display.primaryUnit` и её применение в статус-баре и на дашборде.

## ADDED Requirements

### Requirement: Первичная единица выбирается настройкой с автоматическим режимом
Расширение ДОЛЖНО (SHALL) выбирать первичную единицу расходов настройкой
`claudeStatus.display.primaryUnit` со значениями `auto`, `credits`, `usd` и значением
по умолчанию `auto`. `auto` даёт кредиты для провайдера z-ai и доллары для всех
остальных; явные `credits` применяются только для z-ai, а для провайдеров без кредитной
модели деградируют к долларам; `usd` применяется для любого провайдера.

#### Scenario: Автоединица следует провайдеру
- **WHEN** настройка — `auto`, провайдер — z-ai
- **THEN** первичная единица — кредиты
- **WHEN** настройка — `auto`, провайдер — claude-ai
- **THEN** первичная единица — доллары

#### Scenario: Явные единицы применяются как заданы
- **WHEN** настройка — `credits`, провайдер — z-ai
- **THEN** первичная единица — кредиты
- **WHEN** настройка — `usd`, провайдер — z-ai
- **THEN** первичная единица — доллары

#### Scenario: Кредиты деградируют для провайдера без них
- **WHEN** настройка — `credits`, провайдер — claude-ai
- **THEN** первичная единица — доллары

### Requirement: Первичная единица применяется к стоимостному показу
Расширение ДОЛЖНО (SHALL) показывать стоимостной сегмент статус-бара и стоимостные показания дашборда в первичной единице: доллары — как сейчас; кредиты — сокращённой записью с отличимым знаком кредитов («§2.8k»). Первичная единица управляет всей стоимостной записью: сегментом проектной стоимости, окнами квоты в режиме displayMode: cost и стоимостным тултипом. Бюджеты — исключение: пороги и карточка бюджета всегда в долларах, валюте настроек.

#### Scenario: Кредитная единица отличима от долларовой
- **WHEN** первичная единица — кредиты, стоимостной сегмент показывает 2800 кредитов
- **THEN** сегмент свёрнут до вида «§2.8k» и не начинается со знака доллара

#### Scenario: Долларовая единица показывается как раньше
- **WHEN** первичная единица — доллары
- **THEN** стоимостной показ не отличается от нынешнего долларового

#### Scenario: Cost-режим следует первичной единице
- **WHEN** displayMode — cost, первичная единица — кредиты
- **THEN** окна стоимости показаны в кредитах (например «5h:§2.8k 7d:§9.1k»), а не в долларах

#### Scenario: Карточка бюджета остаётся в долларах
- **WHEN** первичная единица — кредиты, задан дневной бюджет в долларах
- **THEN** карточка бюджета показывает доллары с явной подписью $, без конверсии в кредиты

### Requirement: Скорость прожигания показывается в первичной единице со второй рядом
Расширение ДОЛЖНО (SHALL) показывать на дашборде скорость прожигания в первичной
единице, а для z-ai сопровождать второй единицей («412 кр/ч · $1.42/ч»); для claude-ai
показывается только долларовая скорость.

#### Scenario: z-ai показывает обе единицы скорости
- **WHEN** провайдер — z-ai, скорость — 412 кредитов в час при $1.42 в час
- **THEN** дашборд показывает «412 кр/ч · $1.42/ч»

#### Scenario: z-ai при первичных долларах показывает доллары первыми
- **WHEN** провайдер — z-ai, первичная единица — usd (`primaryUnit: usd`), скорость —
  $1.42 в час при 412 кредитах в час
- **THEN** дашборд показывает «$1.42/ч · 412 кр/ч» — порядок единиц следует первичной

#### Scenario: claude-ai показывает только доллары
- **WHEN** провайдер — claude-ai
- **THEN** скорость показана только в долларах в час

### Requirement: Смена настройки единицы применяется без перезапуска
Расширение ДОЛЖНО (SHALL) перерисовывать статус-бар и дашборд при смене
`claudeStatus.display.primaryUnit` без перезапуска расширения.

#### Scenario: Смена единицы сразу меняет показ
- **WHEN** пользователь меняет `claudeStatus.display.primaryUnit` с `auto` на `usd`
  при провайдере z-ai
- **THEN** статус-бар и дашборд перерисовываются в долларах без перезапуска
